## TransparentBar v0.1.3

Visual identity and asset refresh introducing the official TransparentBar brand icon and multi-resolution assets.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64) with embedded high-resolution application icon
* **transparentbar_bridge-0.1.3.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Updated installer with new application iconography
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

---

### New and improved MAJOR features in 0.1.3:

* **Official Brand Identity**
  * Replaced the generic monitor-style icon with a custom icon depicting a taskbar transitioning from a solid background to clean transparency.
  * Master vector assets (`transparentbar.svg`) included in the project repository.

* **Multi-Resolution Icon Suite**
  * Generated a complete 8-size Windows icon package (`transparentbar.ico`) spanning 16×16, 20×20, 24×24, 32×32, 40×40, 48×48, 64×64, and 256×256 pixels.
  * Crisp rendering across high-DPI desktop scaling, taskbar tray, and file explorer views.

---

### New and improved minor features in 0.1.3 include:
* **Documentation Polish**: Updated README presentation assets, badges, and color palettes to match the brand identity.
* **Binary Resource Integration**: Embedded icon resources into the Windows executable and installer metadata.

> [!NOTE]
> This release focuses on brand and asset polish. For the tray timer crash fix, upgrade to v0.1.4 or later.
