## TransparentBar v0.1.3

A visual update with a logo that represents the application directly: a taskbar changing from a solid background to transparency.

### Changed
- Replaced the monitor-style icon with an original taskbar and alpha-grid mark.
- Updated the executable, tray, installer, and README logo assets.
- Included eight ICO sizes, from 16 to 256 pixels, and an editable SVG master in the repository.
- Aligned the README release badge with the new logo palette.

### Notes
This release changes the identity, not taskbar behavior. The tray interaction issue from v0.1.2 remains; use v0.1.4 or later for that fix. Binaries are unsigned.
