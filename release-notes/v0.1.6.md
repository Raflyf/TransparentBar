## TransparentBar v0.1.6

Refines the maximized-window taskbar connector strip, hides the connector automatically during fullscreen media playback, and adds a native GitHub release update checker in the system tray.

### Added
- **Cek pembaruan** option in the native tray menu and a one-time startup check against GitHub Releases via native WinHTTP. When a newer release is available, TransparentBar displays a tray balloon notification and updates the menu label to **Pembaruan tersedia (vX.Y.Z)** to open the release page directly.
- Automatic fullscreen suppression: hides the connector strip when watching fullscreen videos (YouTube, media players), presentations, or games via `is_docked_above_taskbar` bounds verification and `SHQueryUserNotificationState`.
- Unit tests for fullscreen vs. docked-maximized window bounds and release version tag parsing/comparison.

### Changed
- Tuned the taskbar connector strip from 28 px / 72% top opacity to 42 px height, 90% top opacity, gentler falloff (`1.65`), and a 2 px seam overlap so the transition between maximized windows and the transparent taskbar is smoother and more noticeable without being harsh.
- Positioned the connector strip in the Z-order immediately above `Shell_TrayWnd` rather than unconditional topmost above fullscreen windows.

### Unchanged
Taskbar transparency, original-opacity restoration on exit, and per-user startup settings remain unchanged. No external crates or third-party runtime dependencies were added.

### Notes
Binaries remain unsigned. Windows may display an unknown-publisher warning. Compatibility with every Windows update or third-party shell is not guaranteed.
