## TransparentBar v0.1.6

Enhances the taskbar connector with automatic fullscreen suppression, an integrated GitHub update checker, and tuned gradient profiles.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.6.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Connector overlays during media playback or gaming**
  * Fullscreen applications automatically suppress the connector strip

---

### New and improved MAJOR features in 0.1.6:

* **Automatic Fullscreen Suppression**
  * Detects fullscreen media (YouTube, video players), presentations, and DirectX games via `SHQueryUserNotificationState`.
  * Hides the connector strip automatically during `QUNS_RUNNING_D3D_FULL_SCREEN`, `QUNS_PRESENTATION_MODE`, and `QUNS_APP`.

* **Integrated GitHub Release Update Checker**
  * Adds **Check for updates** to the tray menu and conducts an asynchronous check on startup using native WinHTTP.
  * Notifies the user via a tray balloon and updates the menu label to **Update available (vX.Y.Z)** when a new release is detected.

* **Refined Connector Visual Profile**
  * Increased strip height from 28 px to 42 px with 90% peak top opacity, a gentler 1.65 falloff curve, and a 2 px seam overlap.
  * Adjusts Z-order immediately above `Shell_TrayWnd` rather than topmost, avoiding conflicts with system overlays.

---

### New and improved minor features in 0.1.6 include:
* **Docked-Bounds Verification**: Added `is_docked_above_taskbar` logic to distinguish truly docked maximized windows from floating or offset windows.
* **Unit Tests**: Added test coverage for window bounds verification, version comparisons, and semver parsing.
