## TransparentBar v0.1.4

Targeted bug-fix release resolving tray menu timer conflicts and improving build provenance.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.4.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums
* **BUILD.txt** - Exact build provenance record (version and git commit hash)

### What doesn't come bundled:
* **Third-party timer managers or runtimes**
  * Message pump uses direct native Win32 message filtering

---

### New and improved MAJOR features in 0.1.4:

* **Tray Menu Timer Conflict Resolution**
  * Fixed an issue where opening the tray menu or clicking About caused foreign Windows menu timers to route into the application refresh handler.
  * Eliminates the false `The operation completed successfully. (0x00000000)` crash during tray interactions.

* **Strict Timer Ownership Filtering**
  * Refresh timer messages are now matched strictly by window handle, timer ID (`REFRESH_TIMER_ID`), and callback pointer.
  * Foreign timers pass through unimpeded to `DispatchMessageW`, ensuring Windows menu callbacks operate normally.

---

### New and improved minor features in 0.1.4 include:
* **Nonfatal Removed Ticks**: Handled already-removed refresh timer ticks safely without triggering unexpected shutdowns.
* **Build Provenance**: Embedded `BUILD.txt` in all installer and portable distributions containing exact build commit hashes.
* **Timer Regression Tests**: Added unit tests validating timer ownership filtering against foreign HWNDs and timer IDs.
