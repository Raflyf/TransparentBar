## TransparentBar v0.1.4

A bug-fix release for tray interactions. Opening the tray menu, viewing the license, or changing startup settings no longer routes Windows menu timers into the application's taskbar refresh handler.

### Fixed
- Matched refresh timers by their window, timer ID, and callback value instead of consuming every WM_TIMER message.
- Left unrelated timers to Windows message dispatch so their callbacks still run.
- Made already-removed refresh timer ticks nonfatal, avoiding the false `The operation completed successfully. (0x00000000)` error and unnecessary application shutdown.
- Added a regression test covering foreign window timers, timer IDs, and TIMERPROC callbacks.

### Changed
- Included `BUILD.txt` in installer and portable packages to identify the version and source commit.
- Updated the release policy: features and bug fixes receive new versions; documentation and design-only maintenance do not.

### Unchanged
The XAML transparency bridge and the new taskbar logo are retained. This release does not add blur, color rules, background polling, or a new runtime dependency.

### Notes
Binaries remain unsigned. Windows may display an unknown-publisher warning. Compatibility with every Windows update or third-party shell is not guaranteed.
