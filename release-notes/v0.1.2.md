## TransparentBar v0.1.2

Corrected XAML window enumeration for taskbars that were not discovered by the original callback. The background changes remain on each window's owning UI thread.

### Fixed
- Implemented IVisualTreeServiceCallback2 to enable multi-window enumeration.
- Kept visual trees and saved opacity separate for each UI thread.
- Restored changed elements on their owning dispatcher and waited for all required owners before confirming completion.
- Attempted callback unregistration even when initial enumeration or the wait fails.
- Prevented unconfirmed unregistration from reporting successful session teardown.
- Excluded unrelated, unmodified UI owners from mandatory restoration and reset clean state between sessions.

### Changed
- Reworked the README around installation, usage, compatibility, and contribution.
- Added regression checks for Callback2, thread-local state, session cache reset, and restoration completion.

### Notes
Tray interaction can still trigger a false `The operation completed successfully. (0x00000000)` error in this release. That issue is fixed in v0.1.4. Binaries are unsigned.
