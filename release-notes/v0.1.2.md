## TransparentBar v0.1.2

Core architectural update delivering robust multi-window XAML callback enumeration and per-UI-thread visual tree management.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.2.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

---

### New and improved MAJOR features in 0.1.2:

* **Multi-Window Callback Enumeration (`IVisualTreeServiceCallback2`)**
  * Implemented `IVisualTreeServiceCallback2` to enumerate all taskbar visual trees across complex shell configurations.
  * Resolves missing taskbar elements that were not discovered by the initial callback.

* **Thread-Isolated Visual Tree Tracking**
  * Background modifications and saved opacity records are strictly isolated per UI thread.
  * Restores altered elements on their owning dispatcher, waiting for all thread owners before confirming exit restoration.

* **Safe Teardown & Unregistration**
  * Callback unregistration is enforced even if initial window enumeration encounters errors.
  * Prevents unconfirmed callback unregistration from reporting a false successful teardown.

---

### New and improved minor features in 0.1.2 include:
* **Clean State Reset**: Unmodified UI elements are excluded from mandatory restoration, ensuring clean session resets.
* **Comprehensive Test Suite**: Added regression tests for Callback2, thread-local state tracking, and restoration verification.
