## TransparentBar v0.2.1

Comprehensive feature and optimization update introducing versioned download filenames, installer file version metadata, multi-monitor taskbar support, display sleep/lock energy savings, adaptive connector refresh, and dynamic tray version tooltips.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.2.1.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup-v0.2.1.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64-v0.2.1.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Background polling when locked or monitor sleeping**
  * Sampling completely pauses during session lock or display suspend
* **Colliding download filenames**
  * Installer and ZIP names are uniquely versioned to prevent browser `(1)`, `(2)` auto-numbering

---

### New and improved MAJOR features in 0.2.1:

* **Versioned Download Filenames**
  * Release installer is now named `TransparentBar-setup-v0.2.1.exe` and portable package is `TransparentBar-windows-x64-v0.2.1.zip`.
  * Downloading successive updates no longer collides with previous setup files in your Downloads folder.

* **Installer File Version Header Fix**
  * Fixed an issue where the Inno Setup executable reported `File version: 0.0.0.0` in Windows file properties.
  * Explicitly embedded `VersionInfoVersion=0.2.1.0` and textual product versioning in the installer binary.

* **Multi-Monitor Secondary Taskbar Support**
  * Extended taskbar detection to support secondary monitor taskbars (`Shell_SecondaryTrayWnd`).
  * When an application is maximized on a secondary display, the connector strip seamlessly moves and docks over that monitor's taskbar.

* **Display Sleep & Session Lock Energy Savings**
  * Integrated `WM_WTSSESSION_CHANGE` and `WM_POWERBROADCAST` system events.
  * Completely suspends connector timers and hides the overlay when Windows is locked (Win+L) or displays enter low-power sleep mode, conserving laptop battery.

* **Adaptive Connector Refresh**
  * Operates at 60 ms during active mouse wheel scrolling, tab switching, and cross-fading.
  * Automatically relaxes to 250 ms when screen content settles unchanged for over 1.2 seconds, instantly waking back to 60 ms on the next detected change.

---

### New and improved minor features in 0.2.1 include:
* **Dynamic Tray Tooltip**: Hovering over the system tray icon now displays `TransparentBar v0.2.1` based on compiled package metadata.
* **Synchronized Versioning**: Updated Cargo manifests, PE file resources, Inno Setup manifests, About dialog, and inter-process channels to 0.2.1.
