## TransparentBar v0.1.1

Diagnostic and resilience update adding detailed startup stage tracking, trace logging, and broad dispatcher resolution.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.1.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

---

### New and improved MAJOR features in 0.1.1:

* **Startup Stage Diagnostics & Trace Logging**
  * Bridge initialization failures now report the exact execution stage rather than a generic timeout.
  * Logs detailed startup traces to `%LOCALAPPDATA%\TransparentBar\startup.log`.

* **Diagnostic Inspection Mode (`--diagnose`)**
  * Added a dedicated command-line flag (`transparentbar.exe --diagnose`) to inspect XAML visual tree elements without modifying taskbar opacity.

* **Flexible Dispatcher Resolution**
  * Added support for both `CoreDispatcher` and modern `DispatcherQueue` when resolving XAML dispatchers across Windows revisions.

---

### New and improved minor features in 0.1.1 include:
* **Asynchronous Element Evaluation**: Background elements are automatically reevaluated when parent frames appear asynchronously.
* **Independent Opacity Readback**: `BackgroundStroke` is no longer required for a detected `BackgroundFill` candidate to become ready.
* **Application Icon Embed**: Integrated official application icons into the executable and installer.
