## TransparentBar v0.1.1

Improved startup diagnostics and the first application-specific icons. Bridge failures now include the startup stage instead of only a generic timeout.

### Added
- Application icons embedded in the executable, tray, and installer.
- Startup stage and callback counters for XAML diagnostics.
- A `--diagnose` mode that inspects XAML elements without changing their opacity.
- Startup trace at `%LOCALAPPDATA%\TransparentBar\startup.log`.

### Fixed
- Support for both CoreDispatcher and DispatcherQueue when resolving the XAML dispatcher.
- BackgroundStroke is no longer required before a detected BackgroundFill can become ready.
- Background candidates are reevaluated when their parent frame appears later.
- The original opacity is retained before a change, including when readback fails.
- Cached COM factories no longer retain the session status channel.

### Notes
This version still misses some XAML windows; v0.1.2 adds multi-window callback support. Readiness and tray fixes continue in later releases. Binaries are unsigned.
