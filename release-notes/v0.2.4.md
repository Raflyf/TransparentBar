## TransparentBar v0.2.4

Optional support links for TransparentBar, without changes to the taskbar connector.

### What comes bundled:
- **transparentbar.exe** - Native Windows host application (x64)
- **transparentbar_bridge-0.2.4.dll** - Native taskbar transparency bridge
- **Windows installer** (`TransparentBar-setup-v0.2.4.exe`) - Per-user installation
- **Portable ZIP** (`TransparentBar-windows-x64-v0.2.4.zip`) - Application, bridge, build provenance, and SHA-256 sums

---

### New and improved features in 0.2.4:

- **Buy me a coffee in the tray menu**
  - Opens [the support page](https://yapp.ink/raflyf) in your default browser only when selected.
  - Browser-launch errors follow the existing application error handling.

- **Support information in About / license**
  - Displays the same optional support URL alongside the project and license information.

- **Repository support links**
  - Added a Support section and navigation link to the README.
  - Added a custom funding URL for the GitHub Sponsor button.

> [!NOTE]
> Donations are optional. TransparentBar remains free and open source; it does not open donation pages automatically or handle payments inside the app.

---

### Compatibility and verification
- Connector sampling intervals, color blending, fullscreen behavior, DPI handling, and installer shutdown behavior are unchanged.
- No new dependency, webview, payment SDK, or background network check.
- Regression check keeps the HTTPS destination consistent across the app, README, and GitHub funding configuration.
