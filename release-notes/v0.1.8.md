## TransparentBar v0.1.8

Major architectural overhaul of the taskbar connector, introducing dynamic full-width edge sampling and live updates during scrolling.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.8.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Single-color center pixel approximations**
  * The connector now samples every column across the taskbar width
* **Continuous polling during fullscreen video or gaming**
  * Background sampling remains suspended during fullscreen activity

---

### New and improved MAJOR features in 0.1.8:

* **Full-Width Per-Column Edge Sampling**
  * Replaced the legacy single-pixel center sample with a full-width, four-row edge capture.
  * Each column receives its own local color with horizontal box blur smoothing (`radius=8`), allowing dark margins and bright center panels to coexist naturally.

* **Independent 120 ms Connector Refresh Timer**
  * Added an isolated, window-owned refresh timer that tracks content changes while an app is maximized.
  * Scrolling, switching tabs, and navigating web pages update the gradient automatically without requiring window focus or click events.

* **Strict GDI Synchronization**
  * Enforced checked `GdiFlush()` synchronization before CPU pixel reads to guarantee all BitBlt transfers complete before sampling.

* **Seam-Aware Capture Placement**
  * Adjusted the screen capture rectangle to sample device pixels immediately above the overlay seam (`bar.top - 2 - rows`), eliminating feedback loops.

> [!IMPORTANT]
> If a capture or render operation fails, TransparentBar automatically hides the strip rather than leaving stale or corrupted colors displayed.

---

### New and improved minor features in 0.1.8 include:
* **DIB Section Reuse**: Pre-allocates and reuses 32-bit DIB sections across frames, uploading to `UpdateLayeredWindow` only when column colors change.
* **Geometry Relocation Handling**: Automatically hides the connector if taskbar dimensions shift before capturing the new edge.
* **Deterministic Native Tests**: Added two-frame DIB BitBlt regression tests proving live scanline updates.
