## TransparentBar v0.1.8

Fixes connector color mismatches across the bottom edge of maximized windows and keeps the gradient up to date as content scrolls, without requiring a focus change or click.

### Fixed
- Replaced one center-pixel color with a full-width, four-row edge sample. Each gradient column now uses its own local edge color, so dark margins and light or colored center panels no longer tint the entire taskbar alike.
- Added an independent 120 ms connector refresh while a supported maximized window is active. Scrolling, tab changes, and other visible content updates no longer depend on foreground or window-location events.
- Synchronized GDI bitmap copies before reading their pixels and added deterministic native regression checks using two different captured color frames.
- Samples end above the overlay; moved taskbar geometry hides the old strip before capture. This avoids reading the connector itself after layout changes.
- Bitmap and DC ownership now covers failure paths. Capture or rendering failures hide the strip rather than leaving stale colors visible.

### Resource use
- Reuses capture and gradient bitmaps while active, and uploads a new layered image only when sampled colors or geometry change.
- While no supported maximized window is active, the enabled connector checks eligibility once per second without pixel capture. This also allows recovery when the same window exits fullscreen. Disabling the connector cancels its timer; hidden strips release their bitmap resources.
- Sampling still uses some CPU when an eligible maximized window is idle. No zero-CPU or fixed-memory guarantee is made.

### Unchanged
The connector profile remains 42 px high with 90% top opacity, a 1.65 falloff, and a 2 px seam overlap. Fullscreen suppression, the manual connector toggle, English UI, system-themed tray menu, update dialogs, startup settings, and taskbar restoration remain in place. No dependencies were added.

### Limitations
- Connector support remains limited to the primary bottom-docked taskbar with auto-hide off. Unsupported layouts hide the strip; secondary taskbar connectors are not included.
- Colors are a smoothed approximation of a thin visible screen edge. Text, tooltips, protected content, HDR, and display color processing can affect that sample.
- Native bitmap and timer regression checks do not establish visual compatibility with every browser, player, or Windows build. Binaries remain unsigned.
