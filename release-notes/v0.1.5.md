## TransparentBar v0.1.5

Adds an optional taskbar connector strip for maximized windows with a manual on/off toggle in the system tray menu, plus a native GitHub release update checker and tray notification.

### Added
- Soft gradient connector strip (42 px height, 90% top opacity, 2 px seam overlap) along the top edge of the taskbar when the active foreground window is maximized and docked above the taskbar, sampling the window's bottom edge so the transition into the transparent taskbar is smooth and noticeable without looking harsh.
- Automatic fullscreen suppression: hides the connector strip when watching fullscreen videos (YouTube, media players), presentations, or games.
- **Penyambung taskbar** toggle in the native tray menu (enabled by default, persisted per user under `HKCU\Software\TransparentBar\TaskbarConnector`).
- **Cek pembaruan** option in the tray menu and automatic startup check against GitHub Releases via native WinHTTP; displays a tray balloon notification and updates the menu label to **Pembaruan tersedia (vX.Y.Z)** when a newer release is published.
- Window maximize, restore, and location-change event hooks so the connector updates without continuous background polling.
- Unit tests for connector gradient alpha falloff, premultiplied pixel layout, color decoding, shell-window and fullscreen filtering, and release version comparison.

### Unchanged
Taskbar transparency, original-opacity restoration on exit, and per-user startup settings remain unchanged. No external crates or third-party runtime dependencies were added.

### Notes
Binaries remain unsigned. Windows may display an unknown-publisher warning. Compatibility with every Windows update or third-party shell is not guaranteed.
