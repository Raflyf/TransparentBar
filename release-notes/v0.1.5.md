## TransparentBar v0.1.5

Introduces an optional maximized-window connector strip to bridge the transition between applications and the transparent taskbar.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.5.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Mandatory visual intrusions**
  * The connector strip is completely optional and can be toggled on or off at any time

---

### New and improved MAJOR features in 0.1.5:

* **Maximized-Window Connector Strip**
  * Creates a soft, layered gradient strip at the top of the taskbar when a foreground window is maximized.
  * Samples the edge color of the maximized window to create a seamless aesthetic transition into the transparent bar.

* **Native Tray Toggle with Registry Persistence**
  * Adds a manual toggle option to the tray menu.
  * Preference is stored per-user under `HKCU\Software\TransparentBar\TaskbarConnector` (default enabled).

* **Event-Driven Hook Integration**
  * Tracks window state via `SetWinEventHook` (`EVENT_SYSTEM_FOREGROUND`, `EVENT_OBJECT_LOCATIONCHANGE`), updating without continuous desktop polling.

---

### New and improved minor features in 0.1.5 include:
* **Gradient Math Verification**: Added unit tests for 32-bit premultiplied alpha layout and mathematical falloff curves.
* **Shell Filtering**: Excludes desktop worker windows, taskbars, and core system shells from triggering the connector.

> [!NOTE]
> This initial connector release remained visible over some fullscreen video players. Fullscreen suppression and Z-order refinements are introduced in v0.1.6.
