## TransparentBar v0.1.5

Adds an optional taskbar connector strip for maximized windows, with a manual on/off toggle in the system tray menu.

### Added
- Soft gradient connector strip along the top edge of the taskbar when the active foreground window is maximized, sampling the window's bottom edge so the transition into the transparent taskbar is less abrupt.
- **Penyambung taskbar** toggle in the native tray menu (enabled by default, persisted per user under `HKCU\Software\TransparentBar\TaskbarConnector`).
- Window maximize, restore, and location-change event hooks so the connector updates without continuous background polling.
- Unit tests for connector gradient alpha falloff, premultiplied pixel layout, color decoding, and shell-window filtering.

### Unchanged
Taskbar transparency, original-opacity restoration on exit, and per-user startup settings remain unchanged. No new runtime dependencies were added.

### Notes
Binaries remain unsigned. Windows may display an unknown-publisher warning. Compatibility with every Windows update or third-party shell is not guaranteed.
