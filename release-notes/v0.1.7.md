## TransparentBar v0.1.7

Localization and UI polish update switching all interfaces to English, synchronizing tray menu themes with Windows system preferences, and refining update checks.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.7.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Custom heavy theme engines**
  * Context menus use native Windows dark/light styling via undocumented `uxtheme.dll` ordinals

---

### New and improved MAJOR features in 0.1.7:

* **Complete English Localization**
  * Converted all tray menu items, status notices, About dialogs, and setup wizard tasks to standard English.
  * Menu options: **Taskbar connector**, **Run at sign-in**, **Check for updates**, **About / license**, and **Exit**.

* **Windows System Theme Synchronization**
  * Reads `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme`.
  * Dynamically applies dark or light context menu theming using `uxtheme.dll` ordinals 135 (`SetPreferredAppMode`) and 136 (`FlushMenuThemes`).

* **Explicit Update Confirmation Dialog**
  * Clicking **Check for updates** in the tray menu now always shows an immediate response dialog.
  * Displays an informative message when already on the latest version, or offers a one-click prompt to visit GitHub Releases when a newer version exists.

---

### New and improved minor features in 0.1.7 include:
* **NUL-Safe Header Parsing**: Fixed WinHTTP header parsing where trailing NUL bytes from `WinHttpQueryHeaders` could prevent redirect tag parsing.
* **Enhanced Regression Tests**: Added unit tests covering NUL-padded release tags, semver comparisons, and tray notification routing.
