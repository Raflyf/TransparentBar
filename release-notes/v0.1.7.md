## TransparentBar v0.1.7

Switches the application and installer interface to English, syncs the native tray menu theme with Windows dark/light mode, and ensures manual update checks always display a confirmation dialog.

### Added
- System theme synchronization for the native tray context menu: reads `HKCU\Software\Microsoft\Windows\CurrentVersion\Themes\Personalize\SystemUsesLightTheme` and applies dark or light menu styling via `uxtheme.dll`.
- Direct dialog confirmation when clicking **Check for updates** in the tray menu: displays an immediate dialog when already on the latest version, prompts to open GitHub Releases when a newer version is available, and reports connection errors clearly.
- Unit test covering NUL-padded WinHTTP redirect `Location` headers during release tag extraction.

### Changed
- Changed all tray menu items, dialogs, startup status messages, and Inno Setup installer tasks to English (**Taskbar connector**, **Run at sign-in**, **Check for updates**, **About / license**, **Exit**).

### Fixed
- Fixed `WinHttpQueryHeaders` `Location` header string slicing where trailing buffer NULs prevented redirect tag parsing and suppressed the "up to date" notification.

### Unchanged
Taskbar transparency, the 42 px maximized-window connector strip with fullscreen suppression, original-opacity restoration on exit, and per-user startup settings remain unchanged.

### Notes
Binaries remain unsigned. Windows may display an unknown-publisher warning. Compatibility with every Windows update or third-party shell is not guaranteed.
