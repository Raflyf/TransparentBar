## TransparentBar v0.2.6

Redesigned **Bilah Senja** application icon and warm Charcoal, Copper, Burnt Orange, and Cream installer branding aligned with WallpaperLive and LivelyDesk.

### What comes bundled:
- **transparentbar.exe** - Native Windows host application (x64)
- **transparentbar_bridge-0.2.6.dll** - Native taskbar transparency bridge
- **Windows installer** (`TransparentBar-setup-v0.2.6.msi`) - Per-user MSI installation
- **Portable ZIP** (`TransparentBar-windows-x64-v0.2.6.zip`) - Application, bridge, build provenance, and SHA-256 sums

---

### New and improved features in 0.2.6:

- **Redesigned Bilah Senja application icon**
  - Replaced `transparentbar.svg`, 512×512 `transparentbar.png`, and 8-frame PNG-in-ICO `transparentbar.ico` with the tilted graphite-and-copper translucent dock design over a warm sunset backdrop (`#111111`, `#AE7D57`, `#D9541E`, `#F3EEE3`).

- **Harmonized WiX MSI installer visuals & README branding**
  - Updated `wix-dialog.bmp` and `wix-banner.bmp` to warm Ink Black, Burnt Orange glow, and Cream card framing matching WallpaperLive and LivelyDesk.
  - Updated the README latest release badge accent color to `#D9541E`.
