## TransparentBar v0.2.5

Modern WiX v5 MSI installer, conflict-free bridge upgrades, hardened PE metadata, and optional Saweria support links.

### What comes bundled:
- **transparentbar.exe** - Native Windows host application (x64)
- **transparentbar_bridge-0.2.5.dll** - Native taskbar transparency bridge
- **Windows installer** (`TransparentBar-setup-v0.2.5.msi`) - Per-user MSI installation
- **Portable ZIP** (`TransparentBar-windows-x64-v0.2.5.zip`) - Application, bridge, build provenance, and SHA-256 sums

---

### New and improved features in 0.2.5:

- **Modern WiX v5 MSI installer**
  - Replaced Inno Setup packaging with an uncompressed per-user Windows Installer (`.msi`) using `WixUI_Minimal`, custom dark-slate branding graphics, progress/error text strings, and `MSIFASTINSTALL=7` for faster setup.
  - Marked the versioned taskbar bridge component permanent for upgrades and added automatic startup cleanup of unlocked older `transparentbar_bridge-*.dll` files so upgrades never conflict with `explorer.exe` file locks.
  - Automatically syncs `BRIDGE_FILE` and `StatusChannel` naming with `CARGO_PKG_VERSION`.

- **PE hardening and Windows integration**
  - Embedded an `asInvoker` + `PerMonitorV2` application manifest into `transparentbar.exe` and `VERSIONINFO` resources into `transparentbar_bridge-0.2.5.dll`.
  - Replaced dynamic `LoadLibrary`/`GetProcAddress` lookups for `wtsapi32.dll` and `dwmapi.dll` with direct Windows API bindings.

- **Optional Saweria support destination**
  - Added **Support via Saweria** in the tray menu alongside **Buy me a coffee**, updated the **About / license** dialog, and documented code signing and privacy policies.

> [!NOTE]
> Donations are optional. TransparentBar remains free and open source; it does not open donation pages automatically or handle payments inside the app.
