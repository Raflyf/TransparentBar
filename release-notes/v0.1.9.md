## TransparentBar v0.1.9

Resolves coordinate mismatches and delayed sampling on displays using Windows display scaling (such as 125%, 150%, or 200%).

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.1.9.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Fixed 96-DPI assumptions or hardcoded scale factors**
  * All metrics scale dynamically using the real DPI of the monitor hosting the taskbar
* **Unnecessary background polling**
  * Sampling remains conditioned on maximized window states

---

### New and improved MAJOR features in 0.1.9:

* **Per-Monitor DPI Awareness V2**
  * TransparentBar now declares Per-Monitor V2 DPI awareness at startup.
  * Eliminates DPI virtualization where `GetWindowRect` returned scaled logical coordinates while `BitBlt` captured physical device pixels.
  * Prevents the sampling band from landing several rows above the actual visible application edge on scaled displays.

* **Dynamic Scaling of Connector Geometry**
  * Strip height, seam overlap, sample rows, blur radius, frame overhang, and edge slack are computed dynamically from monitor DPI.
  * At 125% scaling (120 DPI) or 150% scaling (144 DPI), connector elements maintain precise physical pixel alignment without distortion.

* **Scaled Maximized Docking Tolerances**
  * Windows invisible resize frames grow proportionally with DPI scaling.
  * Docked-window detection now adapts to scaled window overhang, preventing false rejections of maximized windows on high-DPI displays.

> [!NOTE]
> `SetProcessDpiAwarenessContext` and `GetDpiForWindow` are resolved at runtime via `GetProcAddress`, preserving full backward compatibility with older Windows 10 releases while enabling Per-Monitor V2 on modern builds.

---

### New and improved minor features in 0.1.9 include:
* **Runtime Verification**: Added automated tests verifying the DPI scaling table, docking decisions from 96 to 288 DPI, and Per-Monitor V2 awareness context.
* **Fallback Safety**: Falls back gracefully to system DPI awareness if Per-Monitor V2 is unsupported by the host environment.
