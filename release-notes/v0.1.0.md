## TransparentBar v0.1.0

The initial public release of TransparentBar: a lightweight, native Rust utility for a clean transparent Windows taskbar.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host application (x64)
* **transparentbar_bridge-0.1.0.dll** - Native injected transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Per-user installation with optional desktop shortcut
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Zero-install standalone archive

### What doesn't come bundled:
* **Blur, tint, or acrylic effects**
  * Provides a 100% clean, clear transparent taskbar background
* **Heavy frameworks or background resource waste**
  * Zero webview, browser runtime, or heavy background polling

---

### New and improved MAJOR features in 0.1.0:

* **Native Transparent Taskbar Background**
  * Renders the Windows 10 and Windows 11 taskbar fully transparent while keeping all app icons, pinned shortcuts, and tray elements in place.

* **Native System Tray Management**
  * Provides a lightweight tray menu with **Jalankan saat login**, **Tentang / lisensi**, and **Keluar**.

* **Optional Sign-In Startup**
  * User-configurable startup setting stored under `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` (disabled by default).

* **Dual Pipeline Architecture**
  * Includes distinct paths for classic Windows taskbars and modern Windows 11 XAML visual trees, with full appearance restoration on application exit.
