## TransparentBar v0.1.0

The first public build of TransparentBar: a native Rust utility for a transparent Windows taskbar, controlled from the system tray.

### Added
- Transparent taskbar background without blur or tint effects.
- Native tray menu with **Jalankan saat login**, **Tentang / lisensi**, and **Keluar**.
- Optional startup at Windows sign-in, disabled by default.
- Separate legacy and XAML taskbar paths, with saved-appearance restoration on exit.
- Per-user Windows installer and portable ZIP packages.

### Notes
This early build has XAML startup and tray issues addressed in later releases. Use the [latest release](https://github.com/Raflyf/TransparentBar/releases/latest) for those fixes. Windows 10/11 x64 is the target; compatibility with every shell or Windows update is not guaranteed. Binaries are unsigned.
