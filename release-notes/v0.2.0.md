## TransparentBar v0.2.0

Comprehensive update refining the maximized-window connector with smooth color cross-fading, twice-as-fast sampling rates, bottom-edge weighted capture, and a trimmed 34 px profile.

### What comes bundled:
* **TransparentBar.exe** - Native Windows host executable (x64)
* **transparentbar_bridge-0.2.0.dll** - Native taskbar transparency bridge
* **Inno Setup Installer** (`TransparentBar-setup.exe`) - Standard per-user installation with desktop shortcut option
* **Portable ZIP Archive** (`TransparentBar-windows-x64.zip`) - Standalone package with SHA-256 verification sums

### What doesn't come bundled:
* **Background bloatware or telemetry**
  * Zero analytics and 0% idle CPU footprint; operates entirely offline on local Win32 APIs
* **External runtimes or browser engines**
  * 100% native Rust binary with static CRT (no WebView2, Electron, or .NET dependencies)

---

### New and improved MAJOR features in 0.2.0:

* **Smooth Color Cross-Fading**
  * Replaced rigid color snaps with an exponential ease (~30% delta convergence per frame).
  * Color changes when scrolling content or changing tabs now transition smoothly over several frames rather than flashing abruptly.
  * Resizing or hiding the strip resets the blend cleanly to prevent ghosting or stale color interpolation.

* **High-Frequency 60 ms Connector Refresh**
  * Accelerated active edge sampling from 120 ms to 60 ms while a supported window is maximized.
  * Allows the connector strip to track rapid mouse wheel scrolling and page navigation in near real-time.

* **Bottom-Edge Weighted Scanline Sampling**
  * Sampled rows are weighted exponentially toward the bottom edge closest to the taskbar.
  * Newly scrolled content entering the viewport is registered immediately instead of waiting for the full multi-row sample buffer to fill.

* **Trimmed Connector Profile**
  * Reduced the base strip height from 42 px down to a sleeker 34 px (at 96 DPI).
  * Preserves the gentle 1.65 falloff curve and 90% peak opacity while creating a subtler, less intrusive bridge into the transparent taskbar.

> [!NOTE]
> The connector refresh timer is strictly adaptive: it operates at 60 ms only when a supported maximized window is active, and drops to an idle 1000 ms check (without pixel capture) otherwise. Disabling the connector completely disarms the timer.

---

### New and improved minor features in 0.2.0 include:
* **Version Synchronization**: Synchronized package version, resources, installer metadata, About dialog, and inter-process status mapping to 0.2.0.
* **Release Supersession**: Fully consolidates the experimental v0.1.10 changes under the permanent v0.2.0 tag.
* **Failure Safety**: Timer allocation or capture failures automatically hide the strip and trace diagnostics rather than freezing a stale gradient.

* **Sampling Geometry**: Samples device pixels immediately above the overlay seam (`overlay_top - sample_rows`), avoiding feedback loops.
* **DPI Compatibility**: All metrics (strip height, seam overlap, sample rows, blur radius, overhang) dynamically scale with `GetDpiForWindow`.
